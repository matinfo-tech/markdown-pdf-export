# Advanced

For people who want more control than [Studio](/studio) gives, or who run the tool from scripts and AI assistants.

If you only want to pick a page style, a font and a header, Studio is enough:

```sh
npx -y markdown-pdf-export studio
```

Everything Studio does ends up in a settings file. The pages below show how to write that file
yourself and what else it can do.

| Page | Read it when you want to |
|---|---|
| [Settings file](/advanced/settings-file) | know where settings live, use a different setup per project, or use the short presets |
| [Per document](/advanced/per-document) | change one document only, from its front matter |
| [Header and footer](/advanced/header-footer) | add page numbers, a title, a date or a logo to every page |
| [Styling](/advanced/styling) | change fonts, code colours, add your own CSS or force page breaks |
| [Content](/advanced/content) | write maths, add a table of contents, use emoji or line breaks |
| [Command line](/advanced/cli) | see every command and flag, or export from scripts and CI |
| [Assistant tools](/advanced/assistant-tools) | connect an AI assistant by hand, or see what it can ask for |
| [Browser](/advanced/browser) | choose which browser draws the PDF, or fix "no browser found" |
| [Recipes](/advanced/recipes) | start from a ready-made header and footer |

Reference pages, for looking things up:
