# Quick start

Turn a Markdown file into a PDF in three steps.

## 1. Get Node.js

Install **Node.js 20 or newer** from <https://nodejs.org>. It comes with `npx`.

You also need **Google Chrome or Microsoft Edge**. If you have neither, run this once after step 2
to download a browser for this tool only (about 200 MB): `npx -y markdown-pdf-export install-browser`.

## 2. Open a terminal

- macOS: open **Terminal** from Applications, Utilities.
- Windows: open **PowerShell** from the Start menu.
- Linux: open your terminal app.

## 3. Paste the Studio line

```sh
npx -y markdown-pdf-export studio
```

Studio opens in your browser. Pick a page style, fonts, paper, header and footer, and check the
live preview. Click **Save**, then **Add to my editor**. Press Ctrl+C in the terminal when you are done.

## Your first export

Open a Markdown file and use one of these:

- In your editor, run the task *Markdown: Export to PDF*.
- Ask your AI assistant: "Export this file to PDF".
- In the terminal: `npx -y markdown-pdf-export report.md`

The PDF is saved next to the Markdown file. If something does not work, run
`npx -y markdown-pdf-export doctor`.
